# Varvara K. — сайт-визитка к выборам в школьное самоуправление

Чистые HTML, CSS и JS, без сборки и зависимостей. Сайт на 4 языках: PL, EN, RU, UA.

## Структура

```
index.html        — разметка страницы
css/style.css     — стили (цвета — в начале файла, блок :root)
js/config.js      — ⚙️ НАСТРОЙКИ: имя, дата выборов, таймер, ссылки, статистика, соцсети
js/i18n.js        — 🌍 ВСЕ ТЕКСТЫ на 4 языках (о себе, программа, политика и т.д.)
js/main.js        — логика сайта
js/games.js       — крестики-нолики и мемори
img/              — картинки
```

## Что и где менять

| Что | Где |
|---|---|
| Тексты (о себе, программа, «почему я») | `js/i18n.js` — блоки `pl`, `en`, `ru`, `uk` |
| Включить/выключить таймер | `js/config.js` → `showCountdown: true / false` |
| Ссылка на Google Форму | `js/config.js` → `googleFormUrl` |
| Соцсети | `js/config.js` → `social` (пустая строка — иконка скрыта) |
| Статистика | `js/config.js` → `goatcounterCode` |

### 📸 Фотографии

Положите файлы в папку `img/` **с такими именами**:

- `img/photo-1.jpg` — главное фото на первом экране (вертикальное, ~4:5)
- `img/photo-2.jpg` и `img/photo-3.jpg` — два фото в разделе «О себе» (вертикальные, ~3:4)

Пока файлов нет, вместо них показываются заглушки. Желательно уменьшить фото до ~1200 px по длинной стороне (вес до 300–400 КБ), чтобы сайт быстро открывался с телефона.

## Посмотреть локально

```bash
python3 -m http.server 8765
```

Затем откройте http://localhost:8765

## 🚀 Публикация на GitHub Pages

1. Зарегистрируйтесь на https://github.com.
2. Создайте новый репозиторий (кнопка **New**), например `varvara-vote`, и сделайте его **Public**.
3. Загрузите файлы. Самый простой способ — на странице репозитория нажать **uploading an existing file** и перетащить туда всё содержимое этой папки. Либо через терминал:
   ```bash
   git init && git add . && git commit -m "First version" && git branch -M main && git remote add origin https://github.com/ВАШ_ЛОГИН/varvara-vote.git && git push -u origin main
   ```
4. В репозитории откройте **Settings → Pages**, в поле **Source** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/varvara-vote/`.

Каждое следующее изменение (новый коммит или загрузка файла) обновляет сайт автоматически примерно за минуту.

## 📊 Статистика (GoatCounter)

1. Зарегистрируйтесь на https://www.goatcounter.com/signup (бесплатно для некоммерческих сайтов).
2. Придумайте код, например `varvara`: статистика будет по адресу `https://varvara.goatcounter.com`.
3. Впишите этот код в `js/config.js` → `goatcounterCode: "varvara"`.
4. GoatCounter не использует cookies, поэтому баннер согласия не нужен. В настройках GoatCounter можно сделать статистику публичной.

Локально (на localhost) визиты не считаются.

## Полезное

- Ссылку на конкретный язык можно отправить так: `.../?lang=uk`, `?lang=ru`, `?lang=en`, `?lang=pl`.
- Без параметра язык выбирается по настройкам браузера; если язык не поддерживается — польский.
- После 15 октября вместо таймера автоматически появится сообщение «Сегодня голосуем!», а на следующий день — «Спасибо за каждый голос!».
